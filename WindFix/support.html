WindFix Support

Spectral repair studio for wind instrument recordings — concert flute, clarinet, saxophone, recorder, dizi & xiao · iOS 17.6+ · fully offline

Quick start

  1. Record — keep your instrument 30–50 cm from the mic. If the meter flashes red, move farther away. Optionally pick a recording preset (e.g. Concert Flute, Clean & Clear) before you start.
  2. Detect — in the editor, run detection. Breaths, clipping and clicks are marked as colored candidates on the waveform and spectrogram.
  3. Select — long-press the waveform to select a range; drag the edge handles to fine-tune.
  4. Process — pick an operation, preview 3 seconds, then apply. Every step becomes a track in the edit history; undo works at any depth and the original file is never modified.
  5. Export — WAV 16/24-bit or M4A, then share or save to Files.

Removing breath sounds

Run detection (or select the breath manually) → Breath Soften. It attenuates only the 2–9 kHz band where breath noise lives, keeping the instrument's tone. Start at −9 dB.

Reducing background noise

Select a moment of pure room noise → Detect menu → Noise templates → Generate. Then select the region to clean and apply Noise Gate at ~50% strength.

About clipping

Clipping cannot be undone — only improved. Improve Clipping rebuilds flat-topped peaks; mild to moderate clipping improves noticeably. Prevention works best: watch the level meter while recording.

Importing audio

Share an audio file from the Files app to WindFix (share sheet or the action row), or record directly in the app. Supported formats: WAV, M4A, MP3, CAF and AIFF.

Buying WindFix

WindFix is a one-time purchase on the App Store — every feature is included. There are no subscriptions, no in-app purchases and no ads. Bought a new device? Just install the app again with the same Apple ID; no restore step is needed inside the app.

Troubleshooting

  • No sound / can't record: Check Settings → Privacy → Microphone → WindFix.
  • Recording cut off: If the app was force-killed mid-take, the saved audio is recovered automatically on next launch.
