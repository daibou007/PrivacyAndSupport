4. Accuracy and limitations

The app implements the standard versions of the algorithms it names, and it tells you its limits rather than guessing past them:

  • greedy colouring returns an upper bound on the chromatic number, not χ itself;
  • Dijkstra requires non-negative weights, and the app refuses to run otherwise;
  • the Hamiltonian search is exhaustive and capped at 12 vertices;
  • the minimum spanning trees require an undirected, connected graph.

A failed run is a stated precondition, never a silent wrong answer. The step narrations are teaching text, not formal proofs for every possible input.
