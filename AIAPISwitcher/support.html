How to Use AI API Switcher

1. Managing Environments

Create — Click "Create New Environment" to start a blank profile.
Import — Use "File -> Import JSON" to load existing configuration files.
Clone & Rename — Right-click on any environment in the sidebar to clone or rename it.

2. Configuring API Endpoints

In the Settings tab, define the Claude Code configuration (JSON format). You only need to define the env node. When applied, the app safely merges this node into your local ~/.claude/settings.json file.

3. Proxy and Router Support

In the Proxies tab, you can enable:

  • Remote Network Proxy (Gost): For bypassing network restrictions. The app runs Gost silently in the background and can auto-kill conflicting ports.
  • Local API Router (CCR): Claude Code Router translates API formats (like Gemini/DeepSeek to Anthropic API) locally.
Tip: Ensure gost and claude-code-router are installed on your Mac and accessible in your system PATH. The app will show a green checkmark when they are detected.

Frequently Asked Questions

Why does the app need file access permissions?

macOS App Sandbox requires explicit permissions to modify files outside its container. AI API Switcher needs access to ~/.claude/settings.json to apply your API configurations.

Where are my configurations saved?

Your environment profiles are securely saved locally on your Mac at ~/Library/Application Support/AIApiSwitcher/envs.json. No data is sent to the cloud.

What does the "Export" button do?

The Export tab allows you to define terminal environment variables (like export ANTHROPIC_API_KEY=...). When applied, the app can inject these into a new Terminal window for immediate use.
