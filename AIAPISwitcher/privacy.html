Privacy Policy

Last Updated: May 2026

Summary: AI API Switcher is a fully offline, privacy-first macOS application. We do not collect, store, or transmit any personal information. All environment configurations and proxy processes happen entirely on your local machine.

1. Introduction

This Privacy Policy describes how AI API Switcher ("we", "our", or "the App") handles information when you use our macOS application. AI API Switcher is designed to work entirely on your device — no account, no server, no tracking.

2. Information We Collect

AI API Switcher does not collect any personal information. Specifically:

  • We do not require you to create an account or sign in.
  • We do not collect your name, email address, or any contact information.
  • We do not use analytics SDKs or track your usage behavior.
  • We do not upload your API keys, configuration files, or any content to any server.

All configurations, environment variables, and proxy settings are stored locally on your Mac and are never transmitted to us.

3. File Access Permission

AI API Switcher requests file access to read and write your Claude Code configuration file (typically located at ~/.claude/settings.json). This access is used strictly to apply your selected API environments and model configurations. No data from these files is uploaded or transmitted.

4. Data Storage

All data generated by the App (saved environments, exported JSON files, app preferences) is stored exclusively on your device, primarily in the macOS Application Support directory. Uninstalling the App and clearing this directory will permanently delete all locally stored data.

5. Third-Party Services

AI API Switcher does not integrate any third-party analytics, advertising, or crash-reporting services. No data is shared with any third party.
