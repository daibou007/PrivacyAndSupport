Common questions

How do I enter sets on the Venn page?

Type comma-separated elements into the Universal Set and Set A/B(/C) fields — a, b, c — and the Venn diagram, region highlight and every operation result update immediately. Tap an element chip to remove it (the app asks for confirmation first). Pick an operation — union, intersection, difference, symmetric difference, complement or the Cartesian product — and the highlighted region, LaTeX result and formal conclusion update together.

Why won't Topological Sort run on my graph?

Topological sort is defined for directed acyclic graphs only. If the loaded graph is undirected, the app says so — load the "Directed · task DAG" template or a directed scene. If the graph contains a directed cycle, the simulation runs until the queue empties and then reports the constraint conflict: a topological order does not exist. Both refusals are stated as results, not errors.

Why does Dijkstra refuse my weighted graph?

Dijkstra's greedy relaxation requires every edge weight to be non-negative. If any edge has a negative weight the runner stops at step one with the precondition conflict — this is the content of theorem TG-DISCRETE-015 in the Theorem Library. Non-negative graphs run to completion with distance labels on every vertex.

How do I add vertices and edges in the Graph Editor?

Pick a mode from the panel. Add Vertex: tap empty canvas. Add Edge: tap the source vertex, then the target — on a weighted graph a weight field appears first. Move: drag vertices, tap to select, drag the canvas to pan, pinch to zoom. Delete: tap a vertex (edges are removed from the list) — every deletion asks for confirmation. The adjacency matrix and adjacency list stay in sync with whatever you draw.

How do I control the algorithm simulations?

Every algorithm — BFS, DFS, Dijkstra, Prim, Kruskal, Topological Sort — is a frame-locked sequence. Use the player to play, pause, step forward or backward one frame, or jump to any line by tapping it in the step log. The speed menu runs from 0.5× to 2×, and Settings sets the global default. Nothing is random: the same graph and start vertex always produce the same steps.

How do I draw a Hasse diagram?

Enter the ground set (for example 1, 2, 3, 6) and strict comparabilities a ≼ b using the two pickers. The app adds the reflexive pairs, completes transitivity, and flags any antisymmetry conflict before drawing. The diagram shows only cover relations — redundant transitive edges are removed — and maximal, minimal, greatest and least elements are marked.

How do I save and load scenes?

Tap the download button in any module's toolbar, name the scene, and the full parameterized state is stored as a .dgscene file. The Scenes page — the folder icon on the hub — lists everything: tap Load to reopen the module exactly as saved. Deletions are permanent, which is why every delete asks for confirmation first and names what is about to go. Scenes you export through the share sheet are safe wherever you sent them.

How do I replay the welcome guide or the home tutorial?

Settings → Guides. The welcome guide and the home-page walkthrough can both be replayed at any time — skipping either is never the last chance to see it.

Does DiscreteGraph work offline?

Yes, entirely. The app performs no network requests at all — every set operation, attribute check, combinatorial count, recurrence term, layout and algorithm step is computed on your device. There are no cloud features, no optional connections and no exceptions.

Is there a subscription or an in-app purchase?

No. DiscreteGraph is a one-time purchase. There is no account, no sign-in, no subscription and nothing to buy inside the app.

Reporting a problem

To help us fix something quickly, include:

  • your iPad model and iOS version;
  • the DiscreteGraph version, from Settings → About;
  • the exact input — the sets, pairs, graph or parameters — copied rather than retyped;
  • what you expected and what happened instead;
  • a screenshot, if the problem is visual.
